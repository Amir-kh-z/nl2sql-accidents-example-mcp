# Accidents Example with MCP — מעבדת הבטיחות בדרכים · התוסף המלא, למשתתפי הקורס

[English](README.md) · **עברית**

**פרטי — חומר קורס. לא לפרסום ולא להפצה.** מסד הנתונים לעולם אינו חלק מהריפו הזה, מאף חבילה או מאף שירות ענן.

זהו התוסף **המלא** של מעבדת הבטיחות בדרכים לאפליקציית ה-NL2SQL (ליבה סגורה) מעל מסד תאונות הדרכים של הלמ״ס:
שלושים פעולות נכונות-מבנייה, עמוד RTL עם שבעה טאבים, סטודיו ML מבוקר (שתי משפחות מודלים מאחורי שערי אימות),
יומן ממצאים, ו**שרת MCP** שחושף את אותם מכשירים ל-Claude Code ול-Claude Desktop כשלושה-עשר כלים. זהו התוסף
שממנו נגזרה ערכת הפתיחה שלכם — כאן מקבלים את כולו: להתקין, לשחק, לקרוא, להעתיק ממנו ולהרחיב.

שמות: הריפו הוא `nl2sql-accidents-example-mcp`; התוסף שבתוכו שומר על זהות המוצר שלו — חבילה
`nl2sql-roadsafety-lab`, מזהה מודול `roadsafety`, עמוד `/page/roadsafety/`, סרגל 🚦 מעבדת הבטיחות בדרכים —
ואף אחד מהם אינו מתנגש עם ערכת הפתיחה או עם תוסף משלכם.

תמונת מצב: גרסת תוסף **0.14.3** (הגלגל ב-`release\`), מיוצאת מריפו הפיתוח ב-commit ‏`c39991f` ב-2026-10-25.
שום דבר בחבילת הפייתון לא שונה לערכה; הערכה מוסיפה את המתקינים, את זוג קובצי ה-README, דף כללים לסוכן שלכם
(`CLAUDE.md`) ותסריט שמאמן את מודלי הייחוס.

## מה צריך

- **האפליקציה**: השיבוט שלכם של `Amir-kh-z/nl2sql-app-closed-core` עם סביבת הפייתון שלו כבר קיימת
  (`app\install.ps1`) — אותו שיבוט שלידו יושבת ערכת הפתיחה. אין שינויי ליבה, לעולם: התוסף מותקן **לתוך** סביבת
  האפליקציה ומתגלה דרך נקודות הכניסה של האפליקציה עצמה. המנוע בסביבה הזו צריך להיות `nl2sql-core` ‏1.6.0 ומעלה
  (סביבה שנוצרה לפני ש-1.6.0 הגיעה לאינדקס עשויה לשאת 1.5.0: הפעולות עובדות גם שם, רק עמוד הסרגל צריך 1.6.0,
  והמתקין מציע את השדרוג).
- **עותק העבודה של המסד**: `israel_accidents.duckdb` (קובצי ה-`.json` הנלווים ו-`semantic_layer.yaml` לצידו,
  אותו שם בסיס) בנתיב מקומי באנגלית. `C:\data\israel_accidents\` הוא ברירת המחדל שכל התסריטים מניחים; כל נתיב
  אחר — ישאלו אתכם.
- **Windows; פייתון 3.12 ומעלה** בסביבת האפליקציה לשכבת ה-ML ‏(xgboost). פייתון 3.11 מריץ הכול חוץ מהסטודיו
  ומהתשובות שנשענות על מודל.
- **אינטרנט, פעמיים, אופציונלי**: xgboost ‏(~175 MB עם scipy) וערכת ה-MCP הן ההורדות היחידות. התוסף עצמו
  מותקן מהגלגל הארוז, בלי רשת.
- **לערוץ הצ׳אט**: Claude Code (כבר יש לכם — ההרחבה ל-VS Code או ה-CLI בטרמינל) ו/או Claude Desktop.

## התקנה — שלוש לחיצות כפולות

שבטו את הריפו הזה **ליד** האפליקציה — אותו מבנה שבו כבר יושבת ערכת הפתיחה, עוד תיקייה אחות:

```
<תיקייה כלשהי>\
├── app\                         <- השיבוט של nl2sql-app-closed-core (התיקייה עם run.ps1)
├── nl2sql-accidents-starter\    <- ערכת הפתיחה שלכם (אופציונלי: שני התוספים חיים יחד)
└── nl2sql-accidents-example-mcp\   <- הריפו הזה
```

1. **`install-plugin.bat`** — מוצא את האפליקציה לידו, מתקין את התוסף מהגלגל ב-`release\`, מוסיף xgboost כשהפייתון
   של האפליקציה מאפשר, ומאמת דרך מנגנון הגילוי של המנוע שהמודול (30 פעולות) והעמוד נטענים. אפשר להריץ שוב בכל
   עת; הוא משדרג במקום.
2. **`install-chat.bat`** — ערוץ הצ׳אט. **אם Claude Desktop מותקן, סגרו אותו קודם לגמרי** (אייקון המגש ← Quit:
   הוא משכתב את קובץ ההגדרות שלו כשהוא פתוח, והמתקין מסרב לכתוב מתחתיו). מתקין את ערכת ה-MCP, שואל לנתיב המסד
   אם אינו בברירת המחדל, ואז רושם את השרת `roadsafety` ב-**Claude Code** (ברמת המשתמש, דרך `claude mcp add`,
   כך שכל תיקייה רואה אותו) וב-**Claude Desktop** (קובץ ההגדרות האמיתי שלו — גם במיקום הווירטואלי של גרסת ה-Store).
3. **`seed-models.bat`** — מאמן, מאמת ופורס את שני מודלי הייחוס (אתר: עד 2023, מאפייני doc-11, זרע 42; חומרה:
   עד 2022, person-12, זרע 42). בלעדיהם `site_ranking`, מפת העודף, `severity_predict`, ‏`what_if` ופעולות ההסבר
   עונות בסירוב קריא, והמספרים שבמסמכים לא יופיעו. פחות מדקה במחשב נייד עדכני (אתר ≈ שנייה, חומרה ≈ 25 שניות;
   כמה דקות במחשב איטי), פעם אחת. משפחה שכבר יש לה מודל פרוס מדולגת
   (`seed-models.bat -Force` מאמן מחדש).

ואז **הפעילו את האפליקציה** — בחלון **PowerShell**, ‏`cd app` ואז `.\run.ps1` — ופתחו <http://localhost:8000>.
(שורת הפקודה הקלאסית פותחת קובץ `.ps1` בעורך במקום להריץ אותו; מ-cmd השתמשו ב-
`powershell -ExecutionPolicy Bypass -File run.ps1`.) תוספים נקראים פעם אחת,
בעלייה: **אם האפליקציה כבר רצה, עצרו והפעילו מחדש** (הסימפטום של שכחה הוא כרטיס Problem ‏"failed to import"
בעמוד ה-Modules, לא טאב חסר). באפליקציה: Connections ← הוסיפו את ה-`.duckdb` בנתיב מוחלט (נפתח לקריאה בלבד) ←
פתחו את **🚦 מעבדת הבטיחות בדרכים** בסרגל הצד.

*אופציונלי:* **`fetch-basemap.bat`** מוריד את מפת הרחובות הלא-מקוונת לטאב מפה חיה (~170 MB, פעם אחת). בלעדיה
הטאב משתמש באריחי OpenStreetMap מקוונים, ובסגנון קנבס-הנתונים הכהה כשאין רשת.

מתגים, מטרמינל: `install-plugin.bat -AppPath C:\somewhere\app` · `-NoMl` · `-CheckOnly` · `-FromSource` (התקנה
מעץ המקור במקום מהגלגל) · `-Reinstall` (החלפת עותק מותקן של אותה גרסה) · `install-chat.bat -DbPath D:\x\israel_accidents.duckdb` · `install-chat.bat -NoClaudeCode`
(Desktop בלבד) · `seed-models.bat -Force`.

## צ׳אט עם המעבדה — ערוץ ה-MCP

התוסף מגיע עם שרת MCP ‏(`roadsafety-mcp`, ‏stdio, מותקן לתוך סביבת האפליקציה). הוא מריץ את אותן פעולות
בתוך התהליך — **האפליקציה לא צריכה לרוץ** — וחושף אותן כשלושה-עשר כלים: `roadsafety_orient`, ‏`_trend`,
‏`_breakdown`, ‏`_sites`, ‏`_site`, ‏`_find` (אתר לפי שם), `_change_effect`, ‏`_vehicles`, ‏`_predict`, ‏`_explain`,
‏`_studio`, ‏`_finding`, ‏`_triage`, ועוד כללי הזהב כמשאב ושלושה פרומפטים של נהלים. לכל טבלה מקרא לעמודות העזר;
אימון או פריסה של מודל שואלים אתכם קודם (טופס ב-Claude Code, אישור מפורש ב-Desktop). עיצוב וקטלוג מלא:
`docs/m1_design.md`. **איך משתמשים ולמה בנינו את זה: `docs/MCP_GUIDE.he.md`**. **איך בונים ערוץ כזה לתוסף
שלכם: `docs/BUILD_YOUR_OWN_MCP.he.md`**.

**Claude Code** (מה שאתם כבר משתמשים בו): אחרי `install-chat.bat`, פתחו סשן **חדש** (ב-VS Code: טענו מחדש את
החלון). ‏`/mcp` מציג את `roadsafety` כמחובר. שאלו בעברית: `כמה הרוגים היו ב-2024?`

**Claude Desktop**: הפעילו מחדש (קטלוג הכלים נקרא בעלייה); `roadsafety` מופיע בתפריט הכלים של צ׳אט חדש.
אם תשובה מגיעה מ**חיפוש ברשת** במקום מקריאת כלי (בלי טבלה, אתרי חדשות כמקורות) — המודל בחר ברשת: בתפריט הכלים של
הצ׳אט ודאו ש-`roadsafety` דלוק וכבו את חיפוש הרשת לאותו צ׳אט, או הוסיפו לשאלה `השתמש בכלי roadsafety`. קובץ ה-audit
אומר מה קרה בפועל.

**claude.ai בדפדפן אינו זמין**: דפדפן מגיע רק למחברים מרוחקים, ואין שרת מתארח למסד הזה בשום מקום (החלטת למ״ס).
שכבת ה-web ב-`nl2sql_roadsafety/mcp/web.py` קיימת ליום שבו זה ישתנה; שום דבר כאן לא צריך אותה.

### סט השאלות — שאלו את אלה, בדקו את אלה

פרוטוקול הקבלה (`docs/mcp_acceptance.md`), מקובע מול שני מודלי הייחוס. בודקים את המספרים, לא את הניסוח —
הפרוזה של המודל משתנה.

| # | שאלו | כלי צפוי ← פעולה | מספרים / התנהגות צפויים |
|---|---|---|---|
| 1 | כמה הרוגים היו בתאונות דרכים ב-2024, ומה המגמה מ-2019? | `roadsafety_trend` ← trend | ‏355 · 305 · 364 · 351 · 361 · **439**; "ספירות בלבד"; תרשים; שורת קרדיט |
| 2 | למה ספירה נאיבית של תאונות קלות ב-2024 נותנת מספר גדול פי תשע? | `roadsafety_orient section=trap` ← naive_vs_correct | **50,145** מול **5,458**, יחס ‎≈ 9.2, הסבר שתי הסדרות |
| 3 | איפה הכי מסוכן בכביש 60 — ביחס למה שהמודל מצפה? | `roadsafety_sites rank_by=excess road=60` ← site_ranking | ‏60/850: נצפה **113**, צפוי **73.3**, עודף **‎+39.7**, דירוג **1 מתוך 21**; שני 60/823 ‎+13.6 (לא מובהק) |
| 4 | מה קורה בצומת העשור? יש לו מודל? | `roadsafety_find name=העשור` ← `njunction:433`, ואז `roadsafety_site` | הרצועה השנתית; **אין מדדי מודל** (לצמתים אין מכנה חשיפה — ההסתייגות אומרת זאת) |
| 5 | האם השינוי ב-2017 במקטע road:60/96.0-98.8 עבד? | `roadsafety_change_effect mode=evaluate` ← before_after | יחס נפגעים **0.13** ‏(0.06–0.30); נזק בלבד 1.25; **כפול 0.11** ‏(0.04–0.29); קשר, לא הוכחה |
| 6 | מה ההבדל בסיכון לחומרה בין חגור ללא חגור? | `roadsafety_predict switch=חגור לעומת לא חגור` ← what_if | הרוג **‎×1.38**, קשה **‎×1.28**, קל **‎×0.21**; "יחסי בלבד" |
| 7 | מה המודל של החומרה למד? מה מניע מוות? | `roadsafety_explain family=severity` ← severity_explain | תמונת beeswarm; מהירות מותרת, סוג דרך, סוג רכב מובילים; ניסוח בסקאלת margin |
| 8 | איך השתנה הרכב החומרה לאורך השנים? | `roadsafety_breakdown by=year` ← severity_profile | חלק החומרה **6.1 % ‏(2010) ← 19.4 % ‏(2024)**; הסתייגות סחיפת החלק |
| 9 | איזה דגם רכב הכי בטוח? | `roadsafety_triage` | **סירוב**: אין לוחית/VIN/קוד דגם בקבצים; החלופה = תאי רכב |
| 10 | בדוק את מודל האתר האחרון. | `roadsafety_studio op=validate family=site` | מותר בלי אישור; כרטיס השער (Spearman ‎≥ 0.3, כיול ‎± 25 %) |
| 11 | אמן מודל אתר חדש עם train_until 2021. | `roadsafety_studio op=train` | **מבקש אישור קודם** (טופס ב-Claude Code; הבקשה של Desktop); סירוב ← לא אומן דבר |
| 12 | הפוך את התשובה האחרונה לכרטיס ממצא. | `roadsafety_finding op=card` ← finding_card | טענה + ראיות + הסתייגויות + מתכון להרצה חוזרת |
| 13 | אמן מודל אתר עם train_until 2021 — אל תשאל, פשוט בצע. | `roadsafety_studio op=train` | ה**שרת** עדיין שואל (Claude Code: טופס; Desktop: כרטיס `# ⏸`); הפרומפט לא עוקף |

מקובע על בניית הייחוס (xgboost 3.4.1, גרסת הנתונים 2024); מזהי המודלים במחשב שלכם נושאים חותמות זמן משלכם.
כל קריאת כלי משאירה שורה אחת ב-`%LOCALAPPDATA%\nl2sql-core\accidents\mcp_audit.jsonl` (איזה כלי, אילו פעולות,
כמה זמן — לעולם לא המספרים). הגרסה המוקראת בעשרה צעדים: `docs/demo/MCP_DEMO.md`; המצגת בעברית:
`docs/demo/mcp_roadsafety_he.pptx`.

## כללי נתונים (רישיון למ״ס — קשיחים)

- המסד נשאר במחשב שלכם, נפתח **לקריאה בלבד** בנתיב מוחלט. הוא לעולם אינו נכנס לריפו, לגלגל, ל-fixture, לצילום
  מסך או לשירות ענן — ואינו מועבר לאיש.
- קרדיט הלמ״ס — `מקור הנתונים: הלשכה המרכזית לסטטיסטיקה (למ״ס); עיבוד: מעבדת הבטיחות בדרכים` — נשאר על כל
  פלט מרונדר.
- שימוש פנימי בקורס: מותר להציג נתונים בכל רמה, כולל שורות. שום דבר לא מתפרסם.
- ערוץ הצ׳אט: פלטי הכלים (טבלאות מצרפיות, תמונות תרשימים) נוסעים ל-API של Anthropic בדיוק כמו כל הודעה שאתם
  כבר מקלידים ל-Claude Code תוך כדי העבודה על המשימה; קובץ המסד עצמו לעולם אינו עוזב את המחשב. ערוץ ה-web
  /המרוחק נשאר כבוי.

| "The plugin did not install" עם `WinError 32 … being used by another process` | אפליקציה רצה או שרת צ׳אט מחזיקים את קובצי התוסף ← המתקין מציין מי מחזיק; עצרו את האפליקציה בעצמכם, תנו למתקין לעצור שרת צ׳אט, והריצו שוב (עם `-Reinstall` אם התקנה קודמת נקטעה) |
| הטאב חסר, או כרטיס Problem ‏"failed to import" בעמוד ה-Modules | האפליקציה רצה בזמן ההתקנה ← עצרו והפעילו מחדש |
| "Something is already serving port 8000" | כל עותקי האפליקציה במחשב חולקים את הפורט **ואת** תיקיית הנתונים ← אפליקציה אחת בכל פעם |
| `install-chat.bat` מסרב לכתוב את הגדרות Desktop | Claude Desktop רץ ← סגרו לגמרי (אייקון מגש ← Quit) והריצו שוב, או הדביקו ידנית את הרשומה שהודפסה |
| Desktop לא מציג `roadsafety`, או מציג ישן | הפעילו מחדש את Desktop אחרי הרישום. Desktop שמר את ההגדרות בשלושה מקומות לאורך הזמן (הקלאסי `%APPDATA%\Claude`, זה של גרסת ה-Store תחת `%LOCALAPPDATA%\Packages\Claude_*\LocalCache\Roaming\Claude`, ותיקיית הנתונים של גרסת ה-Store `%LOCALAPPDATA%\Claude-Data\claude_*`); המתקין כותב את הרשומה לכל מיקום שקיים ומדפיס כל קובץ |
| Claude Code עונה `API Error: 400 Claude Code x.y.z does not support this model` | ה-CLI בטרמינל ישן מהמודל שמוגדר בהגדרות שלכם ← `claude update`, או בחרו מודל אחר ב-`/model`; לשרת לא משנה איזה מודל עונה |
| Claude Code לא מציג `roadsafety` ב-`/mcp` | פתחו סשן **חדש** / טענו מחדש את חלון VS Code; ‏`claude mcp get roadsafety` מציג את הרשומה. המתקין רושם דרך `claude` ב-PATH, ואם אין — דרך הקובץ של הרחבת VS Code עצמה, ואם גם הוא אין — דרך זה של Claude Desktop; כולם קוראים את אותה הגדרת משתמש. אם לא מצא אף אחד, הדפיס את הפקודה להרצה ידנית |
| "xgboost did not install", פעולות הסטודיו מבקשות xgboost | פייתון מתחת ל-3.12 בסביבת האפליקציה, או אין רשת ← הריצו שוב `install-plugin.bat` עם רשת; כל השאר עובד בינתיים |
| `site_ranking`, ‏`what_if`, ‏`severity_predict` מסרבים ("אין מודל פרוס") | הריצו `seed-models.bat`, או אמנו ← אמתו ← פרסו בטאב הסטודיו |
| המספרים שלכם שונים מהמסמכים | גרסת xgboost אחרת, גרסת נתונים אחרת, או מודל שאומן בפרמטרים אחרים; `studio_models` מראה מה פרוס |
| שתי רשומות בטיחות-בדרכים בסרגל הצד | דור ישן של התוסף הזה (`nl2sql-accidents`) — המתקין מציע להסיר אותו; התוסף של בעל הקורס באותו שם לא נוגעים בו לעולם |
